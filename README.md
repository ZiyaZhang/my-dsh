# my-dsh

DeepSeek Harness（DSH）的看板插件原型。它把会话按事项收拢，再加一个叫 my dsh 的助理：能回答问题，把活派给事项里的会话，跟进进度，有事要你处理时主动说。

## 现在能用的

- 左栏 my dsh：上半是看板。事项一节里进行中的事项各占一张卡片，列出最近三条会话和状态（等输入、在跑、失败），悬停一行看它的近况；已归档的事项收在一行里；回顾按天列出最近 14 天的会话，今天和昨天展开，每条写时间、状态、标题、所在事项和近况。
- 会话的近况是标题下的一行：在跑的写正在做的步骤或工具和做了几分钟，在等的写它问的问题或等批准的工具，失败的写错误，其余写最后一条回复的开头。回复开头读自 DSH 为每条会话缓存的轮次大纲，不读会话日志；这个进程里跑的会话按事件随时更新。
- 页面右侧一栏：等你处理列出在等你回答、等你批准或失败了的会话，等得最久的在前；跟进事项列出进行中的事项，每件写最新一条会话的近况，点开进事项。页面窄于约 1100px 时这一栏收起。
- 点开一件事项：顶上一行写目标、会话数和各列的条数；会话按等待输入、工作中、空闲中分三列，卡片写近况，每条能打开或移出；事项能改名、改目标、编辑上下文、归档和恢复。
- 事项的上下文：主工作区、来源（文件夹、文件、PR、文档、链接）和指令。新建事项时就能填，拖进来的文件会复制到这件事项的文件夹里。
- 会话的右键菜单里能加入事项、移出事项，也能直接新建一件事项把它放进去。
- 页面下半是和 my dsh 的对话。my dsh 是一条用 my-dsh 预设的普通会话：能读文件、找文件，不能写文件、跑命令；它每轮读看板索引，能查会话最近的回复，能在事项里开会话、给会话发消息。新建、合并、改名事项它只提议，你在卡片上点了才改；说法对不上唯一的事项或会话时，它给出候选让你点。
- “全部记录”打开 my dsh 的完整对话；“做事记录”按天列出它做过的事和你手动的归类，能撤回的带撤回。撤回一条它开的会话，会停下那条会话，并把它移出事项。
- 状态只来自同一个 DSH 进程：别的进程（比如另开的 profile）正在跑的会话，在这里显示为空闲。

插件只在两种情况下往别的会话里写：my dsh 在你发起的一轮里开会话或发消息。数据在 DSH 数据目录下的 my-dsh/（默认 ~/.dsh/my-dsh/）：matters.json 是事项，assistant.json 是 my dsh 的会话、做事记录和卡片，corrections.jsonl 记你每次纠正（手动加入、移动、移出、在候选卡上选、拒绝提议、撤回），只留在本机。

## 接下来要做的

- my dsh 主动说：会话要你处理、事项停滞。
- 会话自动归进事项。每个自动做的决定都写原因，能撤回。
- 事项分大小：大事项按需开一条主对话来管它的会话，小事项只有看板。

## 安装开发版

需要 DSH 0.2.2-rc.1 或之后的 0.2.x。

```bash
npm install
npm run build
dsh plugin --profile <profile> add link:/path/to/my-dsh
```

重启这个 profile，左栏就有 my dsh。建议先装进单独的 profile 试，不要直接装进日常用的那个。

## 开发

```bash
npm run check
```

依次跑类型检查、测试和打包。
