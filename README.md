# my-dsh

DeepSeek Harness（DSH）的看板插件原型。它把会话按事项收拢，再加一个叫 my dsh 的助理：能回答问题，把活派给事项里的会话，跟进进度，有事要你处理时主动说。

## 现在能用的

- 左栏“看板”：进行中的事项各占一张卡片，列出最近三条会话和状态（等输入、在跑、失败）；已归档的事项收在一行里；回顾按天列出最近 14 天的会话和它们所在的事项。
- 点开一件事项：会话按等待输入、工作中、空闲中分三列，每条能打开或移出；事项能改名、改目标、归档和恢复。
- 会话的右键菜单里能加入事项、移出事项，也能直接新建一件事项把它放进去。
- 状态只来自同一个 DSH 进程：别的进程（比如另开的 profile）正在跑的会话，在这里显示为空闲。

插件不往会话里写任何东西。事项存在 DSH 数据目录下的 my-dsh/matters.json（默认 ~/.dsh/my-dsh/）。

## 接下来要做的

- 看板页下半：和 my dsh 的对话。
- my dsh：一条配了插件工具的会话。它只读不改，改文件、跑命令都派给事项里的会话；会话要你处理、事项停滞和每天简报时主动说。
- 事项分大小：大事项按需开一条主对话来管它的会话，小事项只有看板。
- 会话自动归进事项。每个自动做的决定都写原因，能撤回。

## 安装开发版

需要 DSH 0.2.2-rc.1 或之后的 0.2.x。

```bash
npm install
npm run build
dsh plugin --profile <profile> add link:/path/to/my-dsh
```

重启这个 profile，左栏就有“看板”。建议先装进单独的 profile 试，不要直接装进日常用的那个。

## 开发

```bash
npm run check
```

依次跑类型检查、测试和打包。
